## Descripcion

Este portafolio presenta proyectos nuevos y relevantes creados para mostrar habilidades en React, JavaScript, CSS, Vite, LocalStorage, Git, GitHub y despliegue con Netlify.

## Proyectos incluidos

### Job Application Tracker

- Demo: https://polite-lolly-65a77b.netlify.app/
- Repo: https://github.com/242017/job-application-tracker

Aplicacion para organizar postulaciones laborales con estados, notas, enlaces, filtros y persistencia local.

### Pet Care Planner

- Demo: https://creative-swan-908c1a.netlify.app/
- Repo: https://github.com/242017/pet-care-planner

Aplicacion para organizar tareas de cuidado de mascotas, prioridades, categorias, fechas y notas.
